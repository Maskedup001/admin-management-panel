# Admin Management System (Frontend)

> **Full-Stack Practice Project** > Профессиональная панель управления пользователями, разработанная на Angular. Проект демонстрирует реализацию полноценного CRUD-цикла, работу с асинхронными данными и интеграцию с REST API.

---

## 🔗 Связанный бэкенд
Этот интерфейс работает в связке с серверной частью. Логика сервера, сессионная авторизация на защищенных куках (Argon2, Secrets) и API для этой панели реализованы на FastAPI и находятся в отдельном репозитории:  
👉 [admin-management-backend](https://github.com/Maskedup001/admin-management-backend)

---

## 📋 Описание проекта
Данное приложение представляет собой Single Page Application (SPA) для администрирования системы. Оно позволяет управлять списком администраторов, обеспечивая удобный интерфейс для мониторинга и редактирования данных в реальном времени.

В ходе разработки основное внимание уделялось **архитектуре приложения**, строгой **типизации данных** и созданию **отзывчивого UI**, который мгновенно реагирует на действия пользователя без перезагрузки страницы.

---

## 🛠 Технологический стек
* **Framework:** `Angular 21` — компонентный подход, standalone-компоненты, современный control flow.
* **Language:** `TypeScript 5.9` — использование интерфейсов и типов для безопасности кода.
* **State & Async:** `RxJS 7.8.2` — обработка HTTP-запросов и потоков данных.
* **Forms:** `ReactiveFormsModule` — динамические формы с комплексной валидацией.
* **Backend Communication:** `HttpClientModule` — интеграция с API на FastAPI с поддержкой CORS.
* **Build System:** `@angular/build` — новый билдер на esbuild/Vite.
* **Styling:** `SCSS/CSS3` — кастомная стилизация и адаптивная верстка.

## 🚀 Ключевой функционал

### 1. Управление пользователями (CRUD)
Реализован полный цикл взаимодействия с сущностью "Администратор":
* **Просмотр:** Список всех записей с динамической подгрузкой данных.
* **Создание:** Интуитивная форма добавления нового пользователя.
* **Редактирование:** Обновление данных существующих записей через `PATCH` запросы.
* **Удаление:** Быстрое удаление записей с подтверждением действия.

### 2. Работа с данными и валидация
* **Data Mapping:** Реализована логика трансформации данных при получении ответов от БД. Например, преобразование формата `Bit/Buffer` (MySQL) в логический тип `boolean` для корректной работы переключателей в интерфейсе.
* **Reactive Validation:** Все формы защищены встроенными и кастомными валидаторами (контроль длины логина, обязательность полей, формат даты), что предотвращает отправку некорректных данных на сервер.

### 3. Архитектурные решения
* **Service Layer:** Вся бизнес-логика и запросы к API вынесены в отдельный слой сервисов (`AdminService`), что делает компоненты легкими и удобными для тестирования.
* **Component Communication:** Использование декораторов `@Input()` и `@Output()` (EventEmitter) для эффективной передачи данных между родительскими и дочерними компонентами.

## 📝 История обновлений

Проект был обновлён с Angular 16 до Angular 21 в рамках поддержки актуальности кодовой базы.

**Что было сделано:**
- Пошаговое обновление через `ng update` (16 → 17 → 18 → 19 → 20 → 21).
- Миграция на новый билд-систему: `@angular/build` вместо `@angular-devkit/build-angular`.
- Переход на новый синтаксис control flow (`@if`, `@for` вместо `*ngIf`, `*ngFor`).
- Замена устаревшего `Router.getCurrentNavigation` на `Router.currentNavigation` (signal-based API).
- Обновление TypeScript до 5.9.

## ⚙️ Установка и запуск

1.  **Клонирование репозитория:**
    ```bash
    git clone https://github.com/Maskedup001/admin-management-panel.git
    ```

2.  **Установка зависимостей:**
    ```bash
    npm install
    ```

3.  **Запуск сервера разработки:**
    ```bash
    npx ng serve
    ```

4.  **Доступ к приложению:**
    Откройте браузер по адресу [http://localhost:4200/](http://localhost:4200/)

---

> **Примечание:** Для полноценной работы интерфейса (авторизация, CRUD) параллельно должен быть запущен локальный сервер бэкенда на порту 8000.

> **Примечание:** Этот проект является итогом комплексной практики, отражающим профессиональный рост от основ веб-разработки до создания сложных Full-Stack решений.
